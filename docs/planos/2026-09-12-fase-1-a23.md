## 8. Como trabalhar — o que funcionou em 12/09/2026

**Cada passo fecha assim, nesta ordem:**

1. Teste escrito, código, `npm run typecheck`, testes do trecho (`npx vitest run <arquivos>`).
2. **Sabotagem:** cada trava nova quebrada de propósito, o teste visto vermelho, o código restaurado. Roteiro no apêndice. Teste que continua verde vira teste novo — ou revela código que não protege nada (aconteceu duas vezes nesta fase).
3. Revisão por agente `security-reviewer`, **só leitura**, com a lista de arquivos e as perguntas específicas. Não rodar enquanto a sabotagem altera arquivos.
4. `npm run verificar` inteiro (5 a 7 minutos) — em segundo plano, com aviso quando terminar.
5. `npm run build`.
6. Tela: `preview_start {name: "sbp-local"}`. A sessão da Fabiana (gestora) costuma continuar no navegador do painel; se não, `/entrar` e clicar numa conta `@exemplo.test`. Nunca digitar senha.
7. Commit com `git commit -F <arquivo>` (no PowerShell, mensagem com aspas quebra) e só os arquivos do passo — nunca `.claude/reviews/`.

**Armadilhas que custaram tempo nesta fase:**

- **Nunca dois `vitest` ao mesmo tempo**, nem `vitest` durante a sabotagem: o `globalSetup` apaga `prisma/teste.db` na partida.
- **Nunca `build` ou `typecheck` com o servidor de desenvolvimento aberto** — os dois escrevem `.next`. Parar o preview antes.
- **Depois de `npx prisma migrate dev`, rodar `npx prisma generate`.**
- **Arquivos antigos usam CRLF** (`ingestao.ts`, por exemplo): alvo de sabotagem com mais de uma linha precisa de regex `\r?\n`, ou a sabotagem "não acha o alvo".
- **`exactOptionalPropertyTypes` está ligado:** não dá para atribuir `undefined` a propriedade opcional.
- **`flatMap` que devolve uniões de literais precisa do tipo de retorno anotado**, senão o `tsc` reclama duas vezes.
- **Código só-Node do servidor mora em `src/instrumentation-node.ts`:** `process.stderr` em `instrumentation.ts` gera aviso de Edge Runtime no build.
- **Painel do navegador:** a URL mostrada é sempre `localhost:3000`; confie em `get_page_text`/`find`. O painel de Ajuda aberto cobre os botões da direita — `Escape` fecha. `form_input` depois de navegar exige `read_page` antes. Clique de confirmação em dois passos precisa de `find` entre um e outro.
- **Dado de desenvolvimento para conferir tela:** roteiro `npx tsx <arquivo>.ts` no scratchpad, com `obterPrisma()` — funciona com o `.env`. Só contas e dados sintéticos.

## Apêndice — roteiro de sabotagem

Salvar no scratchpad da sessão (`sabotar.mjs`), editar a lista e rodar com `node sabotar.mjs`. Aplica uma troca por vez, roda os testes indicados, **restaura o arquivo no `finally`** e diz se o teste ficou vermelho. Node, e não PowerShell: `Set-Content` grava BOM e quebra arquivo.

```js
import { readFileSync, writeFileSync } from 'node:fs'
import { spawnSync } from 'node:child_process'

const raiz = 'C:/Vault - Fernando/Sistema - SBP'

// `de` pode ser string (precisa aparecer UMA vez) ou RegExp (use \r?\n entre linhas).
const sabotagens = [
  {
    nome: 'X1 descrição da trava quebrada',
    arquivo: 'src/servicos/exemplo.ts',
    de: 'trecho exato que protege',
    para: 'trecho quebrado',
    testes: ['src/servicos/exemplo.test.ts'],
  },
]

const resumo = []
for (const s of sabotagens) {
  const caminho = `${raiz}/${s.arquivo}`
  const original = readFileSync(caminho, 'utf8')
  const achados = s.de instanceof RegExp
    ? (original.match(new RegExp(s.de.source, 'g')) ?? []).length
    : original.split(s.de).length - 1
  if (achados !== 1) {
    resumo.push(`${s.nome}: ALVO NÃO ENCONTRADO UMA VEZ (${achados})`)
    continue
  }
  try {
    writeFileSync(caminho, original.replace(s.de, s.para), 'utf8')
    const r = spawnSync(`npx vitest run ${s.testes.join(' ')}`, { cwd: raiz, shell: true, encoding: 'utf8' })
    const saida = `${r.stdout}\n${r.stderr}`
    const falhas = saida.split('\n').filter((l) => /^\s*×/.test(l)).map((l) => l.trim()).slice(0, 5)
    const linha = saida.split('\n').find((l) => /^\s*Tests\s/.test(l))?.trim() ?? '?'
    resumo.push(`${s.nome}: ${r.status === 0 ? 'CONTINUOU VERDE — TESTE NÃO PROVA' : 'ficou VERMELHO'} | ${linha}\n    ${falhas.join('\n    ')}`)
  } finally {
    writeFileSync(caminho, original, 'utf8')
  }
}
console.log(resumo.join('\n'))
```

Depois de rodar, confirmar que nada ficou sabotado: `git diff --stat` e um `grep` pelos trechos quebrados.
